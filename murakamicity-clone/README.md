## Murakami City - React (Vite + Tailwind) Clone

This project replicates the design, layout, and core interactions of `murakamicity.com` using React, Vite, TailwindCSS, React Router, Framer Motion, Swiper, and GSAP.

### Tech stack
- React + Vite
- TailwindCSS
- React Router
- Framer Motion
- Swiper
- GSAP

### Getting started
1. Install dependencies
```bash
npm install
```
2. Run the dev server
```bash
npm run dev
```
3. Open the app at the printed localhost URL.

### Build
```bash
npm run build
npm run preview
```

### Structure
- `src/components`: Navbar, Footer, Hero, InfoBadges, MostWanted, Gallery, Layout
- `src/pages`: Home, Menu, About, Contact
- `src/lib/animations.js`: shared animation variants
